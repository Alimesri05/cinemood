# سینمود | Cinemood

**بخش چالش:** وب ۲ — گالری فیلم  
**نام سازنده:** علی مصری  
**ماهیت پروژه:** یک گالری فارسی و راست‌به‌چپ با HTML، CSS و Bootstrap 5؛ بدون JavaScript و بدون بک‌اند.

## اجرای پروژه، قدم‌به‌قدم

1. فایل فشردهٔ پروژه را استخراج کنید و ساختار پوشه‌ها را تغییر ندهید.
2. فایل `index.html` را در یک مرورگر به‌روز باز کنید، یا آن را با افزونهٔ Live Server در VS Code اجرا کنید (آدرس محلی: `http://127.0.0.1:5500/index.html`). برای داده‌های فیلم نیازی به سرور یا `fetch` نیست.
3. روی کارت هر فیلم کلیک کنید تا پوستر، مشخصات، معرفی کوتاهِ اختصاصی همان فیلم و برچسب‌های حالش را ببینید؛ با دکمهٔ بستن، کلیک بیرون پنجره یا کلید Escape آن را ببندید.
4. لینک‌های «ورود» و «عضویت» در تم روشن به `login.html` و `signup.html` و در تم تاریک به نسخه‌های `-dark.html` می‌روند. فرم‌ها نمایشی‌اند و حساب واقعی ایجاد نمی‌کنند.
5. در سربرگ هر صفحه، گزینهٔ «روشن» یا «تاریک» را بزنید. لینک‌های داخلی و مقصد فرم‌های نمایشی شما را در همان تم نگه می‌دارند؛ به‌عنوان مثال `index-dark.html` به `login-dark.html` می‌رود.

> **مرورگر:** پنجرهٔ جزئیات از Popover API استفاده می‌کند؛ به Chrome و Edge نسخهٔ ۱۱۴ به بالا، Safari نسخهٔ ۱۷ به بالا یا Firefox نسخهٔ ۱۲۵ به بالا نیاز دارد.

> بوت‌استرپ RTL نسخهٔ 5.3.3 **فقط به‌صورت فایل CSS** از CDN دریافت می‌شود و برای نمایش صحیح گرید و فرم‌ها به اینترنت نیاز دارد. CSS اختصاصی، فونت Vazirmatn و همهٔ پوسترها محلی‌اند.

**تقسیم کار Bootstrap و CSS اختصاصی:** کلاس‌های `container`، `row`، `row-cols-*`، `col` و `g-4` چیدمان ریسپانسیو را می‌سازند؛ `btn`، `form-control`، `form-label` و `w-100` پایهٔ دکمه‌ها و فرم‌ها هستند. فایل `css/style.css` فقط هویت بصری، رنگ‌ها، کارت‌ها، منوی بدون JS، Popover و دارک‌مود را تکمیل می‌کند.

### قرارداد مشترک داده

پنج کلید مجازِ حال، با همین املای انگلیسی در `data-mood` استفاده می‌شوند:

| کلید | نمایش فارسی | رنگ برچسب |
| --- | --- | --- |
| `happy` | شاد | `#F2A20C` |
| `sad` | غمگین | `#3B7BE8` |
| `angry` | عصبانی | `#E5484D` |
| `surprise` | متعجب | `#8B5CF6` |
| `neutral` | خنثی | `#64748B` |

برای هر فیلم، شناسه، عنوان‌ها، سال، ترتیب ژانرها، ترتیب حال‌ها و امتیاز از نسخهٔ **بدون تغییر** `movies_sample.json` داخل پروژه گرفته شده‌اند. کلیدهای اصلی ژانر در ویژگی `data-genres` کارت حفظ شده‌اند و نام ژانرها فقط **برای نمایش** به فارسی برگردانده شده است. مقدار `poster` در دادهٔ نمونه خالی بود؛ SVGهای محلی، تصویرسازی‌های تازهٔ رابط کاربری هستند و به معنای تغییر رکوردهای نمونه نیستند. معرفی‌های کوتاه فیلم‌ها متن‌های نمایشیِ نوشته‌شده برای این رابط‌اند و به رکوردهای JSON افزوده نشده‌اند. هیچ فایل JSON در زمان اجرای سایت خوانده نمی‌شود.

## ترفندهای CSS-only

**سوییچ تم و حفظ آن بدون جاوااسکریپت:** سه صفحهٔ روشن با `data-theme="light"` و سه نسخهٔ تاریک با `data-theme="dark"` به یک CSS مشترک وصل‌اند. گزینه‌های سوییچ و تمام لینک‌های داخلی هر تم به فایل‌های همان تم اشاره می‌کنند. متغیرهای تاریک با `:root[data-theme="dark"]` اعمال می‌شوند؛ پنج رنگ حال در هر دو تم ثابت‌اند. چون HTML/CSS خالص روی هاست استاتیک به حافظه/کوکی مرورگر دسترسی ندارد، بازکردن **تازهٔ** آدرس پیش‌فرض `index.html` نمی‌تواند انتخاب قبلی را به‌خاطر بیاورد؛ برای ورود مستقیم با تم تاریک، `index-dark.html` را بوکمارک کنید. پیوند «خانه» در نوبار صفحهٔ اصلی به نشانهٔ `#top` در ابتدای سند می‌رود؛ لوگوی فوتر به صفحهٔ اصلیِ همان تم پیوند دارد. در صفحات ورود و ثبت‌نام، لینک‌های نوبار به بخش‌های صفحهٔ اصلیِ همان تم اشاره می‌کنند.

**منوی موبایل:** با انتخابگر `:target` کار می‌کند. دکمهٔ همبرگری لینکی به `#site-menu` است و `.site-header__marker:target ~ .site-header__panel` پنل را باز می‌کند. با زدن هر لینک منو (مثل `#movies`)، هدفِ آدرس عوض می‌شود و منو خودکار بسته می‌شود؛ دکمهٔ بستن هم به `#menu-closed` (بدون عنصر متناظر) می‌رود تا صفحه اسکرول نشود. نشانهٔ `#site-menu` عنصری `fixed` است تا باز شدن منو صفحه را نپراند. در دسکتاپ منو همیشه دیده می‌شود.

**پنجرهٔ جزئیات:** هر کارت یک `button` با `popovertarget` دارد و پنجرهٔ متناظر با `popover="auto"` در لایهٔ بالایی مرورگر باز می‌شود. دکمهٔ داخلی با `popovertargetaction="hide"` آن را می‌بندد. این روش بدون `:target`، بدون `dialog` و بدون JavaScript است و باعث پرش صفحه نمی‌شود. برای Popover API از مرورگر به‌روز استفاده کنید.

**فرم‌های نمایشی:** در تم روشن `action="index.html"` و در تم تاریک `action="index-dark.html"` فقط به گالری برمی‌گردد. ورودی‌ها عمداً `name` ندارند؛ در نتیجه حتی با `method="get"`، ایمیل یا گذرواژه در URL فرستاده نمی‌شود. `required`، نوع ایمیل و حداقل طول رمز را خود مرورگر بررسی می‌کند؛ تطابق دو رمز و احراز هویت، چون بک‌اند و JS نداریم، پیاده‌سازی نشده است.
